# LaTeX research note

**File:** `main.pdf` (14 pages)  
**Source:** `main.tex`  
**Exhibits:** `figures/*.pdf` → symlinks to `../outputs/figures/paper/`

## Compile

```bash
cd paper
pdflatex main.tex
pdflatex main.tex   # second pass for page refs
```

Requires a TeX distribution with `geometry`, `microtype`, `booktabs`, `caption`, `fancyhdr`, `titlesec`, `hyperref`, `xcolor`, `float`, `placeins`, `enumitem`, `amsmath`. On TeX Live Basic, install missing packages with:

```bash
tlmgr --usermode install enumitem booktabs caption fancyhdr titlesec lastpage hyperref xcolor float placeins amsmath amscls oberdiek tools
```

## Design notes

- Equity / credit strategy report layout: cover with key takeaways, running headers, evidence tags [A]–[D].
- Exhibit titles and source notes live **inside the figure PDFs** (generated by `src/paper_figures.py`). The LaTeX file places them without duplicating captions.
- Regenerate exhibits after data changes: `python src/run_analysis.py && python src/paper_figures.py`.
